# Plan

## Steps

1. Run `/explore` if sufficient exploration has not already occurred.
2. Read relevant requirements.
3. Identify affected components.
4. Determine the smallest viable implementation.
5. List files to create.
6. List files to modify.
7. List files to delete.
8. Define tests.
9. Define validation commands.
10. Identify risks.
11. Define explicit non-goals.

## Restrictions

Do not implement code.

## Output

Produce:

- Goal
- Current behavior
- Desired behavior
- Implementation strategy
- Files
- Dependencies
- Tests
- Validation
- Risks
- Non-goals
- Definition of Done
