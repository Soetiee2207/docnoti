# Implement

## Preconditions

An approved implementation plan must exist.

If no plan exists for a complex task, stop and request planning first.

## Steps

1. Read `AGENTS.md`.
2. Read applicable rules.
3. Read the implementation plan.
4. Inspect target files.
5. Implement the smallest correct change.
6. Run targeted tests.
7. Fix failures.
8. Run broader validation when appropriate.
9. Inspect the final diff.
10. Verify no unrelated files were changed.
11. Report the implementation result.

## Restrictions

Do not expand scope.

Do not redesign unrelated architecture.

Do not claim success without validation.
